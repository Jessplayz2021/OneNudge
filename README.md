OneNudge v0.2 SMS demo

Open index.html, or run with a local web server. Enter dummy student data, then click Prepare Student SMS. The page shows an SMS preview on the laptop. The Copy SMS text button can copy the message when clipboard permissions allow. It does not send SMS. Employer Reminder opens your default email app.

No personal information is stored or transmitted by this demo. Do not use real student data without college IT approval. Direct SMS from a college number would require a provider and secure backend, authentication, access controls, and an approved data-processing arrangement.
